# Mirrored repositories

Snapshots of upstream code repositories for the 2025–2026 memory-system papers
identified from *Memory for Large Language Models* (arXiv 2607.25380). See the
top-level [README](../README.md) for which paper each repository belongs to and
whether it is official or a third-party implementation.

Each directory `repos/<owner>__<repo>/` holds the tracked files of the upstream
branch at the commit listed below, exported with `git archive` (no git history;
Git LFS objects and submodules are not included). "folder-only" rows mirror just
the folder relevant to the paper from a large repository. Upstream licenses are
kept in each directory; refer to the upstream repository for the latest code.
